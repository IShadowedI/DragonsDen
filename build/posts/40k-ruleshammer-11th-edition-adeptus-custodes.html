[40k] Ruleshammer 11th Edition: Adeptus Custodes

November 13th, 2026 via Goonhammer

Welcome to 11th Ruleshammer 11th Edition: Custodes a tour of the of their rules and interactions that I’ve been asked about! If you have any Custodes questions you’d like to see answered in a future update to this article please do send them via this form! 

Changelog

  • Published: 2026-11-13

Current Q&A

When do Martial Ka’tahs get declared used?

Whilst mostly straight forward there is a bit of confusion I’ve seen regarding how Martial Ka'tahs are declared and then used. Let’s start by looking at the rule itself.

At the start of your Command phase, friendly ADEPTUS CUSTODES units with this ability are readied. While a friendly unit is readied, you can select one of the ka’tah abilities presented below for that unit to use. If you do, that unit is no longer readied.

Each ka’tah ability will tell you when that ka’tah ability can be used, and the effects that ka’tah ability has on the unit using it.

We recommend placing a token next to each readied unit, removing it when that unit is no longer readied.

It is easy (I think) to read this and come to the conclusion that all aspects of this rule take place in the Command Phase; at least, that’s what I thought on my first read of the rule. Instead, however, it’s more nuanced than that. One part of this rule always happens in the Command Phase: All the units with this ability become “readied.” That always happens.

What you are required to do next however depends on which Martial Ka'tahs you want to use. If you want to use the Conservai Ka'tah then you need to use it next, during the command phase. That’s because the WHEN clause for that Ka'tah is “your Command phase.” The others, though, have WHEN clauses that all occur in different phases; you don’t need to declare these until you want to use them and readied units stay readied until a Martial Ka'tah is used on the unit.

Can I declare a Martial Ka'tah and then use Master of Ka'tahs to re-ready my unit to then have two active simultaneously?

Yes, I think so. The ability causes a non-readied unit to become readied again.

Master of Ka’tahs (Once per battle round, per unit): If this unit is not readied, you can use this ability. If you do, this unit is readied.

This ability is not limited to any specific phase or triggering moment; it can just be used on a not-readied unit. There’s perhaps some debate you could have on when a unit stops being readied but I think it stops being readied when a Martial Ka’tah is used on the unit, rather than when it’s resolved. Otherwise the Start of Phase ones would mean the units are potentially still readied for a significant amount of time while waiting for that ability to happen. So if you were in the Fight Phase and used the Dacatarai Ka’tah on your unit, used at the start of the Fight phase, then use Master of Ka’tahs to ready the unit again, and subsequently declare Kaptaris.

When do Martial Ka’tahs end?

There’s a general rule that if a rule doesn’t state an end timing then they last until the end of the phase.

Persisting Rule Effects 01.02.02

...

If a rule or effect given to a unit does not specify how long it is active for, it is only active for the phase in which it was given.

There are other instances where this rule is relevant throughout the Codex; several of the stratagems don’t specify when their effects end. Sorry, using Honoured Interred on a Dreadnought doesn’t give it that aura all game; just until the end of the phase it was used in.

What does a “Once Per Army” Upgrade mean?

There are several such Upgrades in the Custodes Codex, such as Memento Moritoi or Augury Uplink, available to Dreadnoughts in armies using the Might of Moritoi Detachment. Whilst the main effect associated with the Upgrade tag is that you can take them several times in the same army, that’s actually just part of several rules associated with the tag.

Upgrades: Some enhancements are tagged with ’Upgrade’. Unlike other enhancements:

    • These can be given to non-CHARACTER units.
    • You can include up to three of the same Upgrade in your army (the second and third instances of the same Upgrade do not count towards the total number of enhancements in your army, but you must still spend the stated points cost each time).

So while they can’t benefit from the second effect from this rule, the first Upgrade still counts towards your enhancement limit and their Codex rule limits you to one of them in total, the Upgrade tag is the rule that allows these upgrades to be given to non-CHARACTER units such as all of the Custodes Dreadnoughts.

Unleash the Lions

One of the more thematic stratagems for Custodes, but it obviously causes a number of questions. We aren’t entirely blind on some of them thanks to the recent Warhammer World Championship FAQ released this week, but that document specifies that these answers are not errata or FAQ and currently only apply for the World Championship. Let's look at them one by one and see if they line up with expectations from the rules as written, giving some indication perhaps of if these answers will stick around and be added to the 40k App.

Does using the stratagem destroy the unit it’s used on?

Q: When I target a unit with the Unleash the Lions stratagem, is that unit destroyed?

A: No.

This is pretty important because otherwise using this stratagem would potentially cause the unit to count for mission objectives.

Has the unit I targeted with Unleash the Lions left the battlefield?

Q: When I target a unit with the Unleash the Lions stratagem, does that unit leave the battlefield?

A: Yes.

I’m not clear on what this actually does in 11th edition. They’ve removed a lot of the distinction Warhammer 40k used to have between being “destroyed” and “leaving the battlefield.” I guess there’s no harm in clarifying that the unit isn’t on the battlefield any more, though.

Do persisting effects pass to the new units?

Q: When I target a unit with the Unleash the Lions stratagem, do persisting rules effects pass to the new units (e.g. Fulgrim's Daemonic Poisons ability)?

A: No.

Honestly, this one is probably one of the more disappointing rulings in the FAQ doc for me. I can see the logical reasoning that the stratagem creates three new units out of the models that used to make up one other unit, so effects on that unit don’t pass along. Flavour-wise though this feels quite gamey; that’s not a strong rebuttal by any means, but I can see why people would be disappointed by it. People want the units they cover in Squigs to remain covered in Squigs for as long as Gork (or Mork) intended without wiggling out from the Squigs on a technicality that essentially boils down to:

“Oh that wasn’t me you covered in Squigs; it was my identical twin brother, who just left the battlefield, honest.”

Do the new units get to use “once per battle abilities” even if their original unit has used them?

Q: When I target a unit with the Unleash the Lions stratagem, do the new units have their 'once per battle' abilities even if the original unit used those abilities?

A: Yes.

Honestly surprised by this one as well, considering it’s the same technicality that causes this to be true. I appreciate them having an answer on it, but I don’t think it’s unfair to expect “once per battle” abilities to be usable once per battle.

Custodes Official FAQs

This section will list official GW FAQs when GW shares some. I have not included Q&A from the World Championship rules update here based on its status as a single event document.

These responses are provided by the Warhammer studio and, while many rulings may be adopted as official rules updates in the future, they are currently only considered valid for the World Championships. As a result they will not be appearing in the Warhammer 40,000 app before the event.
